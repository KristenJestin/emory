# Emory's pictures

Emory has no logo yet. Its pictures show the name, set in Bricolage Grotesque Bold and drawn as
outlines, and a scene of a conversation in the kitchen. The accent is `#a99cf2`.

| File | What it is |
|---|---|
| `social-preview.svg`, `social-preview-en.svg` | The banner, 1280×640: the name, one line, and the scene. The French one is the repository's social preview on GitHub. |
| `card.svg`, `card-en.svg` | The scene alone, 1000×520, for share previews. |
| `fonts/` | Figtree, the text of the pictures, so they render the same on every machine. |

The PNGs in `png/` are rendered by `tools/brand.sh` and committed.
